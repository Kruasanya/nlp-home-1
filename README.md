# Law Links Service

FastAPI-сервис, который находит в тексте юридические ссылки (`пп. 1 п. 1 ст. 374 НК РФ`) и возвращает их
в виде `{law_id, article, point_article, subpoint_article}`.

## Запуск

```bash
docker build -t law-links-service .
docker run -d -p 8978:8978 --name law-links-container law-links-service

curl -X POST "http://localhost:8978/detect" \
     -H "Content-Type: application/json" \
     -d '{"text": "Согласно статье 23 Налогового кодекса и ст. 145 Гражданского кодекса"}'
# {"links":[{"law_id":15,"article":"23","point_article":null,"subpoint_article":null},
#           {"law_id":5,"article":"145","point_article":null,"subpoint_article":null}]}
```

Swagger: http://localhost:8978/docs, проверка состояния: `GET /health`.

Без Docker (Python 3.10+):

```bash
pip install -r requirements.txt
python main.py                      # или: uvicorn main:app --host 0.0.0.0 --port 8978
```

## Как устроено

Решение полностью на правилах и словарях: без моделей, старт ~1,5 с, 1–10 мс на текст.
Зависимости сверх шаблона: `rapidfuzz` (расстояние Дамерау–Левенштейна для опечаток) и `snowballstemmer` (склонения).

```
текст ─► normalize ─► tokenize ─┬─► laws.MentionFinder  где какие законы (law_id)
                                └─► refs.RefParser       где какие ст./ч./п./пп. и их значения
                                          │
                                          ▼
                                 extractor.Extractor     какая цепочка к какому закону ─► LawLink
```

1. **Нормализация** (`law_links/normalize.py`) без изменения длины текста: кавычки, тире, `ё`, неразрывные
   пробелы, латинские буквы-двойники в кириллических словах (`cт.`, `HК`, `CК РФ`).
2. **Законы** (`law_links/laws.py`). Индекс строится из `law_aliases.json`: сокращения кодексов, полные названия
   (префиксное дерево по стемам), номера, даты, названия в кавычках. Упоминание акта разбирается как набор
   реквизитов в любом порядке: вид акта + номер + дата + название (`ФЗ от 27.07.2006 № 152-ФЗ «О персональных
   данных»`, `Закона РФ "О защите прав потребителей"`, `Указа Президента РФ № 240`, `ФСБУ 5/2019`).
   Склонения снимаются стеммингом, опечатки в названиях (`Налогвого коедкса`, `«О пчеловосдтве»`) - нечётким
   обходом дерева и сравнением слов. Если номер общий для нескольких актов (580 таких алиасов), выбирается
   акт, уточнённый датой/названием, иначе - по словам названия, встречающимся в тексте. Анафоры
   (`настоящего Кодекса`, `указанного Закона`) получают последний упомянутый акт того же вида.
3. **Цепочки** (`law_links/refs.py`): маркеры `ст./ч./п./пп./абз.` во всех падежах и с опечатками (`пунта`,
   `сттаьи`, `подп.`, `п/п`, `п.п.`), значения `12`, `4.6`, `а`, `«б»`, `в)`, числительные словами
   (`части второй`), перечни (`1, 2 и 3`), диапазоны (`167-170`, `43.2-6`, `а-в`), любой порядок уровней
   (`ст. 105 ч. 2 п. «а»`, `Статья 5, пункт 2, подпункт б`).
4. **Связывание** (`law_links/extractor.py`): цепочка получает закон справа (через связки `и`, `,`, `РФ`),
   а если справа закона нет - закон слева (`НК РФ, ст. 5`). Цепочки без закона из базы отбрасываются.

## Принятые решения

| Случай | Поведение |
|---|---|
| перечни `пп. 1, 2, 3 п. 2 ст. 3` | отдельная ссылка на каждую комбинацию (декартово произведение) |
| диапазоны `ст. 167-170`, `43.2-6`, `пп. а-в` | разворачиваются: 167, 168, 169, 170 / 43.2 … 43.6 / а, б, в |
| `часть` | пишется в `point_article` |
| пункт внутри части `п. 6 ч. 1 ст. 24.5` | часть → `point_article`, пункт → `subpoint_article` |
| четыре уровня `пп. «г» п. 6 ч. 1 ст. 81` | подпункт и пункт, часть отбрасывается |
| нет статьи `п. 10 АПК` | `article: null`, `point_article: "10"` |
| абзацы | отбрасываются (`абз. 2 п. 1 ст. 5` = `п. 1 ст. 5`) |
| закона нет в базе (`рандомного кодекса`, `ФЗ №20-456`, Конституция) | ссылка не возвращается |
| повторы одной ссылки | возвращается один раз, порядок как в тексте |
| буквы | в нижнем регистре, кириллицей |

## Структура

```
main.py               FastAPI: /detect, /health (шаблон задания)
law_aliases.json      база законов
law_links/
  normalize.py        нормализация без сдвига позиций, токены, стемминг
  laws.py             индекс законов и поиск их упоминаний
  refs.py             разбор цепочек ст./ч./п./пп., перечни, диапазоны
  extractor.py        связывание цепочек с законами -> (law_id, article, point, subpoint)
```
